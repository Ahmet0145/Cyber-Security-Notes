# 🛡️ Fundamentals of Computer Engineering & Security Operations

Welcome to my technical documentation and learning repository. As a First-Year Computer Engineering student specializing in Cybersecurity, I created this project to document my learning journey, hands-on lab exercises, and practical insights.

This repository serves as a structured knowledge base covering computer hardware architecture, networking fundamentals, operating system mechanics, and virtualization.

---

## 📌 Repository Structure

| Module / Topic | Core Concepts Covered | Security Perspective |
| :--- | :--- | :--- |
| **01-Computer-Fundamentals** | Hardware components, CPU, RAM, Storage, Motherboard | Bootkits, Volatile Memory Analysis (RAM Forensics) |
| **02-Operating-Systems-Fundamentals** | OS Architecture, Kernel vs. User Space, Windows/Linux | Privilege Escalation, Process Isolation, Patching |
| **03-Software-Basics** | Software Types, Applications, Databases | Code Execution, SQL Injection, Software Vulnerabilities |
| **04-Network-Fundamentals** | Client-Server Model, Protocols, Ports, DNS | MitM Attacks, Port Scanning (Nmap), DNS Spoofing |
| **05-How-The-Web-Works** | Web Architecture, HTTP/HTTPS, Web Browsers | Web App Security, Cleartext Sniffing, WAF |
| **06-Attacks-and-Defenses** | CIA Triad, Threat Modeling, Defensive Controls | Forensics Chain of Custody, Incident Response |

## 🛠️ Key Highlights & Methodology
- **Structured Learning:** Concepts are broken down into **Overview -> Architecture -> Real-World Analogy -> Security & Forensics Perspective -> Hands-on Lab**.
- **Original Content & Paraphrasing:** All technical explanations have been thoroughly paraphrased and enriched with independent research to build an authentic knowledge base.
