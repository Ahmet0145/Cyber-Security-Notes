## 🔬 Documentation Structure

Each vulnerability note strictly adheres to the following layout:
- **Core Concept & Root Cause Analysis**
- **Mapped CWEs (Common Weakness Enumeration)**
- **Attack Scenarios & Proof of Concept (PoC)**
- **Practical Labs** (PortSwigger Web Security Academy / TryHackMe)
- **Remediation & Secure Coding Guidelines**
